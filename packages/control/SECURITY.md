# Security notes: @aigg/control

**Draft.** Trust assumptions, controls and residual risks of this package.

## Inputs

| Input                  | Trust     | Controls                                                                                                                                                                                                                              |
| ---------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rig.contract.json`    | Untrusted | Size limit 1 MiB. Run-time checks of all used fields (ids, numbers, parents, rectangles, tolerances) with stable `E_CONTRACT_*` codes. The contract is not changed.                                                                   |
| Images (PNG)           | Untrusted | Size limit 64 MiB on disk. Width, height and pixel count are checked from IHDR before the pixel data is inflated. Inflate output is limited to the exact size. CRC of each chunk is checked. Only 8-bit RGB and RGBA, not interlaced. |
| Spine `skeleton.json`  | Untrusted | Size limit 16 MiB. Only rotate and translate bone timelines are read. Each key value must be a finite number. Other timelines are listed and ignored.                                                                                 |
| Manual marks JSON      | Untrusted | Size limit 1 MiB. Format id, known keypoint names, finite numbers, image size, and the optional image SHA-256 are checked.                                                                                                            |
| Command-line arguments | Operator  | `node:util` `parseArgs` in strict mode. Options that a command does not use are refused. Model and image names in workflows must be plain file names.                                                                                 |

Color space: pixel values are used as stored and are assumed to be sRGB. ICC profile and gamma chunks are ignored and are listed in the report. PNG alpha is straight alpha.

## Writes

Each command writes into one output directory. The directory must be new, or empty, or `--force` must be given. A symbolic link as the output directory is refused.
Each file is written to a new temporary name with the exclusive flag and then renamed. The rename replaces a link at the target name, so a write never follows a link.
File names come from the code, not from input. `--dry-run` prints the report and writes nothing.

## External effects

Except for the experiment C runner (above): no network access, no subprocess, no shell, and no environment variables. The `workflow` command writes ComfyUI API JSON files. It does not send them to a server and does not load or download a model.
The prompts in the workflows ask for an explicitly adult character with a safe rating. The negative prompt excludes explicit content and minors.

## Experiment C runner (`runner.mjs` in the bundle)

The `bundle` command writes a directory that the owner copies to the GPU host. The runner runs there. It is the only part of this package with network access and model downloads.

| Item                 | Control                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Bundle files         | `run.sh` checks `SHA256SUMS` (all files, the runner too). The runner checks each file against `bundle.json`, refuses paths that are not plain relative names, and refuses links.                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Model list           | The approved files are fixed in the runner source. A bundle with any other model list stops with `E_BUNDLE_MODELS`. The workflows can use only allowed core node types and the approved file names.                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Downloads            | Only the pinned `https://huggingface.co/<repository>/resolve/<commit>/<file>` URLs. HTTPS only, no credentials, no token. Size limit and SHA-256 check during the stream. The file gets its final name only after both agree. A failed download removes the `.part` file.                                                                                                                                                                                                                                                                                                                                                  |
| Existing model files | Must be regular files with the approved SHA-256. Another value stops the runner. It never replaces a model file. Model folders can be symbolic links (Runpod volume layout); the link target is used and reported.                                                                                                                                                                                                                                                                                                                                                                                                         |
| ComfyUI              | Only `http://127.0.0.1:<port>`, no redirects, time limits on each request. The runner opens no port and needs no public endpoint.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Generations          | Exactly the two bundle runs. The runner records a submission intent (with a `client_id`) in `state.json` before `POST /prompt`, and the prompt id after the answer. A lost or failed prompt is an error, never a new submission. A lost answer to `POST /prompt` gives `E_SUBMISSION_AMBIGUOUS` on this run and on each repeat run, with a manual check of the ComfyUI queue and history. Only an HTTP 4xx refusal removes the intent. A second run after PASS reads the images and `SHA256SUMS` again: if they agree with `result.json`, it runs nothing; if not, it stops with `E_RESULT_CHANGED` and does not generate. |
| Results              | A real directory (not a link), mode 0700, files 0600, written through a temporary name. PASS only after the images and `SHA256SUMS` read back with the same SHA-256. A lock file stops a second runner; Ctrl+C removes it.                                                                                                                                                                                                                                                                                                                                                                                                 |
| Log                  | `run.log` (JSON Lines): events, hashes, prompt ids, ComfyUI versions and GPU names. No environment values, no headers, and no query strings of redirected download URLs. Untrusted text is cut and limited to printable ASCII.                                                                                                                                                                                                                                                                                                                                                                                             |

## Residual risks

- A whole input file is read into memory (at most 64 MiB for an image).
- An image at the pixel limit (4096 x 4096) needs about 64 MiB of RGBA memory, and the side-by-side sheet needs four times that.
- The workflow JSON was not run against a live ComfyUI server. A node name or input can be wrong for the server version. Check it on the first run.
- Model files are executable input for the generation host. The runner checks the SHA-256 of the two approved files, but ComfyUI loads them. A matching hash proves the file is the approved one, not that the file is safe.
- The runner trusts ComfyUI on the loopback interface. Another process on the GPU host could answer on that port. Use a Pod only for this experiment.
- Node.js `fetch` can use proxy environment variables when `NODE_USE_ENV_PROXY` is set. Do not set proxy variables on the Pod for this run.
- The runner checks that the downloaded file is the approved file. It does not check the TLS chain beyond the Node.js defaults.
- The runner gives at most one submission per run, not exactly-once delivery. ComfyUI has no idempotency key for `POST /prompt`. After `E_SUBMISSION_AMBIGUOUS`, the owner decides by a manual check whether the prompt was queued.
- The fake ComfyUI in the tests implements only the endpoints that the runner uses. The first real run is the first test against a real ComfyUI version.
